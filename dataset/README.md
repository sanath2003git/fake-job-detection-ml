# Dataset

## Dataset Name

Real or Fake: Fake Job Posting Prediction (EMSCAD)

## Description

The dataset contains job postings used for detecting fraudulent
and legitimate job advertisements.

## Target Variable

`fraudulent`

- `0` = Legitimate job posting
- `1` = Fraudulent job posting

## Dataset Size

17,880 job postings with 18 features.

## Source

Kaggle - Real or Fake: Fake Job Posting Prediction

The dataset is used locally for the project and is not committed
to this repository.
