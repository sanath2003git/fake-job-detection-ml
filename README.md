# Fake Job Posting Detection Using Machine Learning

## Project Overview

This project focuses on detecting fraudulent job postings using
traditional machine learning and natural language processing.

## Algorithms

- Logistic Regression
- Random Forest
- Support Vector Machine (SVM)

## NLP Techniques

- Text preprocessing
- Text cleaning
- TF-IDF Vectorization

## Dataset

Real or Fake: Fake Job Posting Prediction (EMSCAD)

- 17,880 job postings
- 18 features
- Target variable: `fraudulent`
